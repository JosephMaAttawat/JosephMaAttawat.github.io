# Attawat Assavanadda — Academic Website

This folder is ready for a GitHub Pages user site.

## Upload to GitHub
Upload these files to the root of `JosephMaAttawat/JosephMaAttawat.github.io`:

- `index.html`
- `styles.css`
- `profile.jpg`
- `cv.pdf`

Then go to **Settings → Pages** and choose **Deploy from a branch → main → / (root)**.

Your site will appear at:
`https://josephmaattawat.github.io/`

## Editing later
For simple text changes, open `index.html` on GitHub, click the pencil icon, edit, and commit.
